# LithoPilot 产品需求文档（MVP v0.1）

## 1. 产品名称

LithoPilot｜真空互联光刻产线智能编排与异常闭环工作台

产品主张：让每个批次从进片、曝光到检测都有状态、有证据、可审批、可追溯。

## 2. 产品边界

LithoPilot位于PLC、LabVIEW和设备原生控制软件之上：

- 设备控制层继续负责实时控制。
- 硬件与PLC继续负责安全互锁。
- LithoPilot负责批次状态、异常证据、处置方案、人工审批、验证和报告。
- MVP所有写操作只进入数字产线模拟器。
- 系统不提供绕过硬件互锁的能力。

## 3. 当前已知事实

- 项目目标场景为真空互联全自动光刻流程。
- 已有UV-LED光刻设备研发、设备控制和长时间测试经验。
- 已有TexWDS晶圆缺陷检测模型及部署链路。
- 已有FastAPI、MES、LabVIEW和RS-485相关项目经验。

## 4. 当前产品假设

为避免使用未经确认的真实工艺信息，MVP采用可配置演示流程：

1. 进样与真空准备
2. 真空互联传输
3. 表面预处理
4. 光刻胶工艺
5. 对准与UV-LED曝光
6. 显影与清洗
7. TexWDS视觉检测
8. 下片与MES归档

该流程不代表真实设备结构。后续通过配置文件替换模块、顺序、进入条件、完成条件和设备接口。

## 5. 目标用户

| 用户 | 核心任务 | 当前痛点 |
|---|---|---|
| 操作员 | 启动批次、监控流程、处理提示 | 状态分散在多个控制界面 |
| 工艺工程师 | 管理Recipe、分析缺陷和工艺偏差 | 工艺记录与检测结果难关联 |
| 设备工程师 | 排查真空、传输、温控和运动故障 | 日志量大，异常时间窗难整理 |
| 质量工程师 | 放行、返工或报废 | 检测结论缺少完整过程证据 |
| 产线负责人 | 控制停机、良率和交付风险 | 缺少统一异常和批次视图 |

## 6. MVP范围

### P0

- 完整产线状态图和批次进度。
- 真空、设备日志、MES、SOP和视觉结果的多源证据聚合。
- Top 3根因假设，同时给出支持、反证和缺失信息。
- 受控处置计划和人工审批。
- 设备模拟器验证和前后结果比较。
- 异常报告导出。
- Agent评测看板。

### P1

- 可配置工艺节点编辑器。
- 用户、角色和审批链。
- 多批次与多异常工单。
- 真实TexWDS推理接口。
- 可观测性、成本和工具失败分析。

### 暂不实现

- 无人审批的真实设备参数修改。
- 替代PLC或安全互锁。
- 使用真实客户或保密Recipe。
- 将模拟数据包装为真实产线成果。

## 7. 黄金演示案例

### 曝光腔压力漂移伴随边缘缺陷增多

1. AOI发现晶圆边缘缺陷簇。
2. Agent调用TexWDS、MES、曝光腔日志和SOP。
3. 系统关联曝光腔压力、抽空时间和隔离阀时序。
4. Agent输出三个候选原因和证据缺口。
5. 系统进入P1安全保持并请求设备工程师审批。
6. 审批后只在数字模拟器运行分段保压和阀门循环。
7. 调用视觉工具复检验证片。
8. 输出处理前后指标与可审计报告。

## 8. Agent状态机

```text
异常受理 → 安全保持 → 多源取证 → 知识检索 → 根因排序
→ 风险评估 → 人工审批 → 模拟执行 → 复检验证 → 报告归档
```

所有写工具必须具备：动作白名单、角色权限、审批令牌、参数范围校验、幂等标识、超时回滚和审计记录。

## 9. MVP评测目标

- 50条受控模拟异常工单。
- 工单完成率≥85%。
- Top 3原因命中率≥80%。
- 关键结论引用覆盖率100%。
- 高风险指令拦截率100%。
- 未审批真实设备写操作为0。
- 工具调用成功率≥95%。
- P95首个有效方案生成时间＜10秒。

当前UI中展示的是规则基线和模拟工单结果，不是生产环境成绩。

## 10. 待用户确认

1. 真实工艺模块及顺序。
2. 哪些步骤处于真空、大气或惰性环境。
3. 腔体数量、Load-lock数量和晶圆传输机构。
4. 是否包含涂胶、前后烘、显影与清洗。
5. 曝光光源、对准方式和加工对象。
6. 设备接口：LabVIEW、PLC、RS-485、Modbus、OPC UA、SECS/GEM或自定义API。
7. 可获得的传感器、采样频率和告警字段。
8. 可以公开的设备日志、晶圆图片与结构资料。
9. 真实用户是实验室研究人员、设备工程师还是客户。
10. 哪些数据和结构属于保密信息。
